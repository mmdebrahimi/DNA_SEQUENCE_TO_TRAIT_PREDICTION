# The 2×2 — PRE-REGISTRATION (frozen before any solve)

**Date:** 2026-08-20 · **Status:** frozen before execution
**Panel:** *P. putida* nitrogen — the 4th cell, which completes organism × substrate-axis.

## Why this panel is worth running

Three panels are done, and P2 (the flat-deficit fraction) came out **differently each time**:

| | carbon | nitrogen |
|---|---|---|
| **E. coli** | 76.9 % | 91.1 % |
| **P. putida** | 70.4 % | **?** |

That 70–91 % spread is currently unexplained, and I have been quoting it as a range for exactly that
reason. The missing cell turns the spread into a **discriminating experiment**: with all four, the
variation can be attributed to the organism or to the substrate axis, because each hypothesis predicts a
*different number* for the same cell.

## Pre-registered predictions

**P1–P3 as before** (the replication check), on the 4th panel:

| # | prediction | bar |
|---|---|---|
| P1 | ratio distribution bimodal; threshold band near-empty | **< 1 %** in [0.001, 0.05] |
| P2 | missed-essential cells mostly FLAT | **≥ 50 %** |
| P3 | per-cell beats the best-constant null | **> 0** |

**P4 — the discriminating one, frozen with both branches named in advance:**

| hypothesis | claim | predicted P2 | band (±10 pp) |
|---|---|---|---|
| **H-organism** | the flat fraction is a property of the ORGANISM/model | ≈ 70.4 % | **60.4 – 80.4 %** |
| **H-substrate** | it is a property of the SUBSTRATE AXIS (C vs N) | ≈ 91.1 % | **81.1 – 100 %** |
| **H-neither** | it tracks something else (panel size, condition chemistry, model coverage) | — | outside both bands |

The two bands are disjoint and jointly cover 60.4–100 %, so a P2 in that range **must** select exactly
one branch, and a P2 below 60.4 % rejects both. This is pre-committed: whichever branch the number picks
is what gets reported, including `H-neither`.

**Honest limit, stated before the result:** n=1 per cell. This discriminates between two hypotheses on a
single new measurement; it does not *establish* either. A clean H-organism or H-substrate answer is a
**hypothesis promoted to leading candidate**, never a settled mechanism.

## Substrate (probed before freezing, per R2)

`feba.db` Keio-style `expGroup='nitrogen source'` for `orgId=Putida`: **52 distinct sources**, of which
**27 map to `iJN1463` exchanges**:

- **9** reuse the curated E. coli `NITROGEN_EXCHANGES` map verbatim (ammonium, D/L-alanine, glycine,
  arginine, asparagine, glutamine, L-serine, putrescine).
- **18** by **EXACT metabolite-name match** against the model's own names after stripping salt/hydrate
  forms — e.g. assay `Adenine hydrochloride hydrate` → `EX_ade_e` whose metabolite is named `adenine`;
  `spermidine` → `EX_spmd_e` named `spermidine`. Every proposal was printed with the model's own
  metabolite name and inspected; there are no near-misses in the accepted set.

**Fuzzy matching is deliberately NOT used.** A hand-guessed mapping in the stress probe paired
`sodium fluoride` with `EX_fe2_e` (ferrous iron) and would have manufactured a data point; only exact
post-normalization equality is accepted here, and the normalization is pinned by test.

27 conditions is the **largest panel in the series** (E. coli carbon 25, E. coli nitrogen 13, P. putida
carbon 13).

## Method (frozen)

- Model `iJN1463`; labels Fitness Browser `orgId=Putida`, `expGroup='nitrogen source'`, `fit < -2.0`;
  `FRAC = 0.01`; NaN growth → essential.
- **Medium contract:** glucose held as the fixed carbon source; the test compound opened as the sole
  nitrogen source; **`EX_nh4_e` and every one of the 27 candidate N exchanges closed first**, so residual
  ammonium cannot make every condition silently score as ammonium.
- **Several sources supply carbon too** (the amino acids). True of the real assay as well — this is
  biology, not a modelling error — but these are not nitrogen-only perturbations.
- Determinism: the same claim-level gate (zero call flips + identical headline metric + derived safety
  margin ≥ 1000), `processes=1`, redaction on failure.

## Named caveats

1. **n = 1 per cell** — see the honest limit above.
2. **27 of 52 sources**; P. putida's assay is rich in amines and lactams `iJN1463` does not carry.
3. **Panel sizes differ across the 2×2** (25/13/13/27), so P2 could in principle track panel size —
   which is exactly what `H-neither` covers.
4. **`iJN1463` is less curated than `iML1515`**; an organism-looking effect could be a model-quality effect.
   Those two are **not separable** by this design, and the write-up must say so rather than claiming
   "organism".
